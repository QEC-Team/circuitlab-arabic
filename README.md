# CircuitLab Arabic

محاكي الدوائر الإلكترونية **CircuitJS1** بواجهة عربية، مهيأ للتعلّم والتجربة على الجوال والآيباد والكمبيوتر.

[افتح المحاكي](https://qec-team.github.io/circuitlab-arabic/)

## المزايا

- واجهة عربية واتجاه من اليمين إلى اليسار.
- دعم كامل للشاشات الصغيرة والكبيرة ولمس الشاشة.
- محاكي دوائر تفاعلي يعمل مباشرة من المتصفح.
- أمثلة جاهزة للدوائر الكهربائية والإلكترونية.
- ترجمة عربية شاملة لقوائم وأدوات المحاكي.
- بناء ونشر تلقائي عبر GitHub Pages.

## الاستخدام

1. افتح المحاكي من الرابط أعلاه.
2. اختر عنصرًا من القائمة لإضافته إلى مساحة العمل.
3. انقر أو المس العنصر لتعديل خصائصه.
4. استخدم قائمة **أمثلة** لتشغيل دوائر جاهزة.

## التطوير

يُبنى الموقع تلقائيًا عند كل تحديث لفرع `main`، ثم يُنشر عبر GitHub Pages.
